# Thermomix & Cooking Companion

## Purpose

Create one practical family meal plan from household constraints and convert it into a beginner-friendly Thermomix workflow with minimal separate cooking.

## MVP capabilities

- Thermomix model profile
- household meal preferences and constraints
- refrigerator and pantry input
- seven-day meal plan
- shared base meal with member-specific variants
- consolidated shopping list
- step-by-step cooking session
- timers and appliance instructions
- leftover planning
- taste, acceptance, and tolerance feedback

## Thermomix instruction contract

Each executable step must specify:

- ingredients and quantities
- preparation state
- vessel or accessory
- time
- temperature
- speed
- direction or reverse mode
- measuring-cup state
- safety note when relevant
- expected result
- recovery instruction when the expected result is not reached

## Approval boundary

Recipe recommendations may be generated automatically. Purchases, calendar changes, messages, and external device actions require explicit user approval until separately governed.

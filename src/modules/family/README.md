# Phoenix Family Module

Phoenix Family is owned by EO Billy and provides the shared Family Core plus specialized family companions.

## Initial structure

- `core/` shared household context, permissions, profiles, routines, and learning signals
- `cooking/` Thermomix and cooking planning, recipe variants, shopping, guided sessions, and feedback
- `household/` household tasks and inventory
- `calendar/` family scheduling and conflict detection
- `kids/` guardian-controlled child support
- `finance/` household budgeting and cost planning

## Current delivery target

The first executable vertical slice is the Thermomix & Cooking Companion.

## Safety boundary

No medical diagnosis, autonomous purchasing, unsupervised child interaction, or uncontrolled external action is permitted.
